# Self-hosted webfonts

These are the Latin WOFF2 builds previously served to Word Web by Google Fonts. Keeping
them in the repository removes Google Fonts as a runtime dependency without changing
the site's typography. They are used by the main page and the full RMLP logo asset.

- `courier-prime-regular-latin.woff2` and `courier-prime-bold-latin.woff2` — Courier
  Prime v11
- `fraunces-variable-latin.woff2` — Fraunces v38
- `libre-franklin-variable-latin.woff2` — Libre Franklin v20

Each family is licensed under the SIL Open Font License 1.1. The family-specific
copyright notice and complete license text are in the corresponding `OFL-*.txt` file.
